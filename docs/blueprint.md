# **App Name**: PLKAPK Hub

## Core Features:

- Auth-Protected Marketplace: User registration and secure authentication using Supabase to restrict APK downloads to registered members only.
- Dynamic Discovery Engine: Card-based Home Screen featuring categorized apps, recently added software, and top downloaded highlights.
- Smart App Summary: A feature powered by generative AI that acts as a tool to distill long app descriptions into concise, feature-rich bullet points.
- Progressive Download Manager: A user-facing download button that tracks progress in real-time and increments global download counters.
- Interactive App Profiles: Google Play-inspired detail pages including screenshot galleries, version tracking, and user rating displays.
- Unified Admin Dashboard: Secure interface for admins to manage APK uploads, organize categories, and review download statistics.
- Cloud Media Repository: Scalable storage system using Supabase buckets for housing large APK binaries, icons, and high-resolution screenshots.

## Style Guidelines:

- Primary Color: Vibrant Mint Green (#2BB594) to evoke a fresh, modern tech aesthetic.
- Background: Clean Mist (#F2F7F6), a heavily desaturated tint of the primary mint to reduce eye strain.
- Accent Color: Deep Emerald (#2B8B77) for call-to-action buttons to provide strong contrast against the mint and white.
- The font 'Inter' will be used for both headlines and body text to achieve a machined, objective, and neutral Look similar to professional app stores.
- A mobile-first, responsive grid layout utilizing rounded cards (16px radius) and ample whitespace for a breathable design.
- Modern, thin-line stroke icons in the primary mint shade for navigation and category identification.
- Smooth slide-in transitions for app galleries and micro-interactions when hovering over app download buttons.
